## Правила

1. Определи тему запроса пользователя.
2. Верни только одну релевантную ссылку, соответствующую теме запроса.
3. Не перечисляй остальные ссылки.
4. Не придумывай ссылки.
5. Если несколько формулировок относятся к одному сервису, используй соответствующий раздел ниже.
6. Если вопрос не относится ни к одной из перечисленных тем, не используй этот скилл.

## Формат ответа

1–2 предложения с коротким заголовком раздела.
