# Добавление кандидатов в пул (add-to-rotating-list-top600)

Скилл описывает методологию **добавления кандидатов на позицию**. Является дополняющим к скиллу `search-rotating-top600`.

## Методика

1. Проверяем, что пользователь выбрал людей **из предложенных нами кандидатов**. Если нет — возвращаем сообщение о необходимости выбора из предложенных.
2. Для добавления вызываем тул `update_rotatable`. Вся необходимая для аргументов информация уже получена ранее:
   - `target_person_id` — лист с `person_id` выбранных пользователем кандидатов;
   - `talent_pool_id` — номер пула, полученный ранее из тула сохранения рекомендаций (`saved_rotatable`);
   - ТН запрашивающего руководителя не передаём — его подставляет сервис.
3. В результате возвращается сообщение об успехе или неуспехе. Если было получено сообщение об успехе — вернём пользователю **ссылку на пул** (`talent_pool_url`), которая была получена ранее.
