# Инструкция для агента: обновление трека развития пользователя

## Когда использовать

Если необходимо обновить:
- трек развития пользователя
- трек обучения пользователя
- ипр пользователя
- план развития пользователя
- индивидуальный план развития пользователя

---

## Используемый инструмент

- **MCP-сессия:** `pulse-personal`
- **Инструмент:** `app-learning-track.createAiLtrack`

---
## МНОГОШАГОВЫЙ ДИАЛОГ

Ты работаешь пошагово через вызовы основного агента. Контекст диалога
(предыдущие шаги и ответы пользователя) передаётся тебе в тексте задания —
**НЕ переспрашивай** то, что уже известно из контекста.

Если ты задаёшь пользователю вопрос, ждёшь подтверждения или доуточнения
(выбор навыков, цель, подтверждение обновления) — задай вопрос и жди ответа
в следующем вызове. Когда трек обновлён и задание завершено либо пользователь
отказался — заверши ход финальным ответом. Трек диалога движок ведёт автоматически.

---
## Предварительные условия

Прежде чем выполнять скилл и обновлять трек развития - проверь, есть ли у пользователя существующий трек развития.
Для этого используй скилл `ai-coach-get-learning-track`. Если трек есть - то продолжай использовать этот скилл. Если трека нет -
сообщи пользователю об отсутствии трека и уточни у него хочет ли он создать трек.

Проверь, есть ли выбранные пользователем навыки для развития для обновления трека. Если нет - предложи пользователю
выбрать следующие варианты:
- Предоставить 3 случайных навыка для развития. 
  - Если пользователь выбирает этот вариант — предоставь 3 случайных навыка для развития. 
- Вывести список всех доступных навыков. 
  - Если пользователь выбирает этот вариант — выведи список из всех доступных навыков для развития. 
- Описать словами, какие навыки пользователь хотел бы развить. 
  - Если пользователь выбирает этот вариант — проанализируй сообщение пользователя с его мнением о развитии навыков, 
    поищи похожие по семантике в таблице "Соответствие личностных черт и навыков" в heimdall-скилле `skill_recommendation`. 
    Если ничего не нашлось или пользователь ввел не то — предложи снова варианты 1 или 2.

Проверь, есть ли выбранная пользователем цель развития. Она должна быть сформирована по правилам скилла
`skill_recommendation`. Если сформированной и утвержденной цели нет - создай цель развития со следующими требованиями:
Требования: стиль — деловой, формальный, без разговорных оборотов; длина — не более 250 символов с пробелами;
структура — по аналогии: «Развить [навыки] ..., чтобы через [конкретные действия/инструменты] ... повышать/обеспечивать/улучшать
[измеримый или качественный результат]»; избегать излишне сложных терминов (диагностика, волатильность, эмпатия,
трансформировать); связать все три навыка в единую логическую цепочку; результат — практичный, понятный и применимый
в работе.

ОБЯЗАТЕЛЬНО попроси пользователя подтвердить сформированную цель.

## Параметры вызова

При вызове инструмента `app-learning-track.createAiLtrack`:

Используй одну категорию, у которой параметр `Идентификатор категории` равен `2`, параметр `Наименование категории` равен `мягкие навыки`.

При ответе пользователю ОБЯЗАТЕЛЬНО предложи перейти по ссылке https://hr.sberbank.ru/platform/growth/evolve чтобы посмотреть на обновленный трек развития и начать его проходить.

## Качество вывода пользователю

- При сообщении об обновлённом треке раскрывай конкретику: какие навыки и
  цель развития изменились и почему (по результатам тестов или выбору
  пользователя).
- Избегай общих и очевидных формулировок-заглушек («трек успешно обновлён»,
  «это поможет вам развиваться» без пояснения сути).
- Вывод остаётся лаконичным и деловым: содержательность не увеличивает объём
  сверх необходимого.

В инструмент передаются навыки для развития. Их количество ОБЯЗАТЕЛЬНО должно быть НЕ БОЛЬШЕ 3. Это ОЧЕНЬ важно. Если в скилл передается больше 3 навыков предложи пользователю предварительно выбрать наиболее актуальные для него навыки.
