# Поиск сотрудника по ФИО

## Шаг 1. Разобрать запрос

Выпиши из запроса то, что названо: фамилию, имя, отчество.

Если пользователь никого не назвал («расскажи про меня») или назвал себя в
третьем лице («сделай эссе про Анну Петрову», а это его ФИО из служебного
блока), человек уже известен: бери ФИО и `person_id` из служебного блока
системного промпта и переходи к шагу 4.

## Шаг 2. Вызвать `search_persons_by_fio`

`search_persons_by_fio` вызывается **всегда**, даже если фамилия есть в
приоритетном списке из шага 3: в списке сокращённые инициалы, а для следующих
шагов нужны полное ФИО, табельный номер и актуальная должность из кадровой
системы.

Как искать:

- только по фамилии, если из имени в запросе есть одна буква;
- разговорную форму («Наташа», «Саша») сначала раскрой до полного имени
  («Наталья/Наталия», «Александр/Александра»);
- если в слове «ё» и результат пустой, повтори с «е»;

  (например, «Сергей Попов» вместо Анатолия Попова) — это другой человек:
  ищи дальше по правилам шага 4.
- `person_id` не совпал со списком, но человек в выдаче один — бери его,
  уточнять не нужно. Если в списке есть его полный тёзка и в выдаче их двое,
  приоритет у записи из списка.
